05 — Emotional Design

6 Principles for Trust-First UX

Fintech users feel anxiety, hope, fear, and pride. Each design decision either amplifies or diffuses these emotions. Here's how we architect for confidence.

01 / 06
🔐
Radical Transparency
Every number has a source. Every fee is surfaced before action. Never hide information in the happy path — distrust is built in the micro-moments of concealment. Show exchange rates, processing times, and exact amounts before confirmation.
Trust-building Disclosure-first Pre-confirmation
02 / 06
⚡
Perceived Speed
Optimistic UI updates, skeleton loaders timed to 200ms, progress indicators on all async operations. Real latency is acceptable; perceived latency is the enemy. A 400ms fade-in feels faster than an instant no-feedback action.
Optimistic UI Skeletons Progress states
03 / 06
🎯
Progressive Disclosure
Show one primary action per screen. Advanced options live behind "More" — never pollute primary flows. Users scanning their balance shouldn't see investment risks. Each screen has a single emotional job: reassure, inform, or request.
1 CTA/screen Focus Cognitive load
04 / 06
🎖️
Earned Celebration
Micro-celebrations for first transfer, savings goal met, portfolio milestone — but only when earned. Confetti on every tap cheapens wins. Reserve delight animations for genuine achievements; restraint makes them feel real and motivating.
Milestone moments Restraint Motivation
05 / 06
🛡️
Safe Error Recovery
Errors in finance feel catastrophic. Red should be precise and calm — never alarming. Inline validation, not post-submit. Offer exact correction paths: "Replace '!' with a letter." Give users an escape hatch before every destructive action.
Inline validation Undo patterns Calm errors
06 / 06
🌒
Dark as Calm Signal
Dark interfaces reduce visual fatigue during repeated daily check-ins. They signal premium and seriousness — aligned with high-value financial contexts. Deep blacks anchor the eye; gold accents draw attention without panic. Darkness = focus, not fear.
Eye-fatigue Premium perception Attention

07 — Motion Tokens

Animation & Easing System

Motion in fintech must convey reliability. Nothing should feel bouncy, playful, or unpredictable. Measured, purposeful transitions build trust.

--ease-enter
cubic-bezier(0,0,0.2,1)
Elements entering the screen. Starts fast, ends slow — natural deceleration like an object settling.
--ease-exit
cubic-bezier(0.4,0,1,1)
Elements leaving the screen. Starts slow, ends fast — urgency of departure without abruptness.
--ease-standard
cubic-bezier(0.4,0,0.2,1)
State changes, hover transitions. Smooth in both directions. Used for 90% of UI transitions.
--dur-instant
80ms
Button press feedback, checkbox toggles. Too fast to notice but critical for feeling responsive.
--dur-fast
150–200ms
Tooltip appear, dropdown open, icon swap. Standard micro-interaction duration for UI element reveal.
--dur-slow
400–600ms
Page transitions, chart drawing, success states. Deliberate pace signals weight of the financial action.
